## ExUI 能力

**ExUI 适配**

### 根入口导出冲突别名

公共根入口使用带 `Reui` 前缀的名称解决组件模块间的名称冲突。应从 `@exre/exui` 导入这些准确名称，不能假设原始模块局部名称也被导出。别名包括排程辅助函数 `ReuigetDayKey`、`ReuiexpandRecurrence`、`ReuiMAX_OCCURRENCES`，以及 `ReuiBuildIndexOptions` 等类型。完整名单以维护中的导出清单为准。

```tsx verify
import { ReuigetDayKey } from "@exre/exui"

export const getScheduleDayKey = ReuigetDayKey
```

## Components 与 Blocks

**Components 是基础组件**，提供按钮、输入框、对话框等独立的界面能力。

**Blocks 是基础组件的组装**，将 Components 组合成可复用的界面区块。下面的欢迎卡片由 Card 与 Button 等基础组件组装而成。

## 基本用法

```tsx verify
import "@exre/exui/style.css"
import { Button, Card, CardContent, CardHeader, CardTitle } from "@exre/exui"

export function WelcomeCard() {
  return <Card><CardHeader><CardTitle>欢迎</CardTitle></CardHeader><CardContent><Button type="button">开始</Button></CardContent></Card>
}
```
