title: 密度
description: 对消费 ExUI 密度变量的控件应用标准或紧凑几何。
---

标准密度是默认值。在控件子树加 `.density-compact` 启用紧凑值，可与任一主题组合。默认尺寸的 Button、Input、Textarea、Select、NativeSelect、InputGroup 消费密度变量。显式尺寸及复杂控件布局可能保持固定，应逐个核对；挂在子树之外的浮层也需要同一密度作用域。

{/* exui-capabilities:begin:docs */}
## ExUI 能力

**ExUI 新增**

### 密度与根字号缩放

紧凑密度作用域会改变 `Button`、`Input`、`Textarea`、`Select`、`NativeSelect` 和 `InputGroup` 的默认几何尺寸。显式尺寸和复杂组件布局并非都会随该作用域缩小。CSS 中的 `rem` 尺寸随根字号变化。部分第三方组件只接受数字尺寸；ExUI 在 DOM 边界换算自己的默认值，并在根字号变化后更新。调用者显式传入的数字仍是像素，不应再次换算。

```tsx verify
import { Button, Select } from "@exre/exui"

export function CompactControls() {
  return <div className="density-compact">
    <Button type="button">保存</Button>
    <Select options={[{ value: "a", label: "甲" }]} defaultValue="a" />
  </div>
}
```

## 基本用法

```tsx verify
import "@exre/exui/style.css"
import { Button, Input } from "@exre/exui"

export function CompactControls() {
  return <div className="density-compact"><Input aria-label="名称" /><Button type="button">保存</Button></div>
}
```
