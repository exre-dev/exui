ExUI 的内建可缩放默认值以 16px 设计基准写成 `rem`。根字号设为 20px 时，控件、字号、间距、图标、普通圆角和 Glass 模糊按 20/16 缩放；只接受数值的定位与虚拟布局 API 使用实时换算后的像素值。库本身不设置根字号。细边框、焦点环、阴影、胶囊圆角与边框补偿维持固定。

显式数字参数仍表示像素：`sideOffset={8}`、`indent={20}`、列宽和受控 resize 状态不会被重新解释。接受 CSS 长度的参数可以传入 rem 字符串。DOM 测量值、SVG 内容坐标、图表数据与签名笔迹保持原语义。

通过内置 `Recharts` 和 `TanStackTable` 命名空间使用已适配的 React 默认尺寸；Toaster、Resizable、MessageScroller 也会缩放其自有默认值。底层非 React API `TanStackTable.constructTable` 保留上游像素默认值；InputOTP 私有密码管理器预留与探测仍为 40px/18px。文档主题适配已命名的 Fumadocs 位移动画与滚动条，预设版本由应用自行安装。根字号也影响应用中其他 `rem`，无需缩放时保持 16px。

## ExUI 能力

**ExUI 新增**

### 密度与根字号缩放

紧凑密度作用域会改变 `Button`、`Input`、`Textarea`、`Select`、`NativeSelect` 和 `InputGroup` 的默认几何尺寸。显式尺寸和复杂组件布局并非都会随该作用域缩小。CSS 中的 `rem` 尺寸随根字号变化。部分第三方组件只接受数字尺寸；ExUI 在 DOM 边界换算自己的默认值，并在根字号变化后更新。调用者显式传入的数字仍是像素，不应再次换算。

请阅读[密度与根字号缩放](./density.mdx)，了解完整用法。

## 基本用法

```tsx verify
import "@exre/exui/style.css"
import { Button } from "@exre/exui"

export function ScalableAction() {
  return <Button type="button">随根字号缩放</Button>
}
```
