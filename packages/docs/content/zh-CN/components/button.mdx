Button：以清晰的视觉层级发起操作。

{/* exui-capabilities:begin:docs */}
## ExUI 能力

**ExUI 新增与适配**

### ExUI 操作按钮

ExUI `Button` 使用共享 Token 和胶囊圆角。`ActionButton` 复用同一套变体和尺寸配方，但将圆角覆盖为 `0.75rem`，呈现普通圆角。默认尺寸读取共用密度变量：标准密度为 `2.25rem`，紧凑密度为 `2rem`。显式 `xs` 在两档密度下均为 `1.5rem` 高；`sm`、`lg` 和图标尺寸保留各自的几何 Token。根字号为 16px 时，上述标准、紧凑与 XS 高度分别为 36px、32px 与 24px。两者都有 `default`、`danger`、`destructive`、`outline`、`secondary`、`ghost`、`link` 变体；`destructive` 是危险态的兼容别名。Glass 单独启用，仍保留危险色与焦点状态。非表单提交操作请设置 `type="button"`。

```tsx verify
import { ActionButton, Button } from "@exre/exui"

export function ActionChoices() {
  return <div>
    <Button type="button">保存</Button>
    <Button type="button" variant="outline">预览</Button>
    <Button type="button" variant="ghost">更多</Button>
    <ActionButton type="button">继续</ActionButton>
    <ActionButton type="button" variant="danger" glass>删除</ActionButton>
  </div>
}
```

**ExUI 新增**

### 共用 Glass 材质

`glass` 属性与精确的 `ex-glass` 类名都可启用 ExUI 材质；每个表面分别选择，包括 Select 弹层。先导入 `@exre/exui/style.css`。如需可选折射，每个 document 挂载一个 `GlassSeed`。它渲染不可见的 SVG 滤镜定义，不占可见布局内容，并非 Provider，可在服务端渲染；没有它也有基础材质。浏览器支持检测只确认滤镜声明可被接受，不能证明折射被正确绘制；关键视觉效果需在目标浏览器检查。

本家族支持 Glass 的公开组件: `Button`, `ActionButton`。

请将此表面保留在常规的组件组合中；这个封装只为该表面启用 Glass。

```tsx verify
import type { ComponentProps } from "react"
import { Button } from "@exre/exui"

export function GlassExample(props: ComponentProps<typeof Button>) {
  return <Button {...props} glass />
}
```

请阅读[共用 Glass 材质](../exui/glass.mdx)，了解完整用法。

**ExUI 新增**

### 密度与根字号缩放

紧凑密度作用域会改变 `Button`、`Input`、`Textarea`、`Select`、`NativeSelect` 和 `InputGroup` 的默认几何尺寸。显式尺寸和复杂组件布局并非都会随该作用域缩小。CSS 中的 `rem` 尺寸随根字号变化。部分第三方组件只接受数字尺寸；ExUI 在 DOM 边界换算自己的默认值，并在根字号变化后更新。调用者显式传入的数字仍是像素，不应再次换算。

请阅读[密度与根字号缩放](../tokens/density.mdx)，了解完整用法。

## 基本用法

先确定按钮是点击还是提交操作，再选择与操作优先级一致的变体。

### 当前示例源码摘录

```tsx source="c-button-1"
import { Button } from "@exre/exui"

<Button>{copy("Default", "默认")}</Button>
```
