Scrollspy：滚动时跟踪当前内容分节。

## 基本用法

给分节设置稳定 id，让导航项指向对应锚点。

### 当前示例源码摘录

```tsx source="c-scrollspy-1"
import { Scrollspy } from "@exre/exui"

<Scrollspy offset={50} targetRef={parentRef} />
```
