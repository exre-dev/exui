## ExUI 能力

**ExUI 适配**

### 紧凑组件内边距

ExUI 将默认 Card 内边距、`CommandEmpty` 及 DataGrid 空表和筛选空提示的上下、Gantt 无资源提示四边、纵向 `TimelineItem` 非末项的底部 padding 统一为 `1rem`（16px 根字号下为 16px）。`DialogContent`、`AlertDialogContent`、`SheetHeader` 与 `SheetFooter` 的默认四边 padding 均为 `1.5rem`（16px 根字号下为 24px），与 ReUI 一致。空状态仅在对应提示渲染时生效；时间轴末项不额外增加底部 padding。调用方仍可用类名覆盖默认值。

请阅读[紧凑组件内边距](./card.mdx)，了解完整用法。

- [在线示例](../../../../examples/c-gantt-1/)

**ExUI 新增**

### 密度与根字号缩放

紧凑密度作用域会改变 `Button`、`Input`、`Textarea`、`Select`、`NativeSelect` 和 `InputGroup` 的默认几何尺寸。显式尺寸和复杂组件布局并非都会随该作用域缩小。CSS 中的 `rem` 尺寸随根字号变化。部分第三方组件只接受数字尺寸；ExUI 在 DOM 边界换算自己的默认值，并在根字号变化后更新。调用者显式传入的数字仍是像素，不应再次换算。

请阅读[密度与根字号缩放](../tokens/density.mdx)，了解完整用法。

**ExUI 适配**

### 根入口导出冲突别名

公共根入口使用带 `Reui` 前缀的名称解决组件模块间的名称冲突。应从 `@exre/exui` 导入这些准确名称，不能假设原始模块局部名称也被导出。别名包括排程辅助函数 `ReuigetDayKey`、`ReuiexpandRecurrence`、`ReuiMAX_OCCURRENCES`，以及 `ReuiBuildIndexOptions` 等类型。完整名单以维护中的导出清单为准。

请阅读[根入口导出冲突别名](../getting-started/quick-start.mdx)，了解完整用法。

## 基本用法

先提供任务日期与依赖关系，再渲染时间轴和拖动交互。

### 当前示例源码摘录

```tsx source="c-gantt-1"
import { Gantt, GanttView } from "@exre/exui"

<Gantt defaultDate={new Date(EXAMPLE_EPOCH)} defaultEvents={bars} resources={RESOURCES}>
  <GanttView />
</Gantt>
```
