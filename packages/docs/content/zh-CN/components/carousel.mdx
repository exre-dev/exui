Carousel：依次浏览一组视觉项目。

## 基本用法

将幻灯项放在同一轮播中，并为导航控件提供清晰标签。

### 当前示例源码摘录

```tsx source="c-carousel-1"
import { Carousel, CarouselContent, CarouselPrevious } from "@exre/exui"

<Carousel>
  <CarouselContent />
  <CarouselPrevious />
</Carousel>
```
