Field：组合控件、标签、帮助文本与错误状态。

{/* exui-capabilities:begin:docs */}
## ExUI 能力

**ExUI 新增**

### 独立 Field 组合

`Field`、`FieldContent`、`FieldLabel`、`FieldDescription` 与 `FieldError` 组合设置行和展示值，不注册表单状态。在真实可聚焦控件上放稳定 ID，并让 `FieldLabel htmlFor` 使用相同 ID；通过 `aria-describedby` 显式关联说明和当前错误的 ID。有错误时设置 `aria-invalid`。这些原语不推断子控件 ID，也不继承 Form 布局默认值。非交互展示值使用 `asChild` 加 `span` 呈现文本标题。

精确横向配方为每项建立独立 inline-size 容器，并查询其子行。在 21.75rem（9rem 标题 + 12rem 内容 + .75rem 间隔）时启用双列，只对 FieldContent 限宽和对齐；低于阈值时上下堆叠，并将内容恢复为全宽。标题与说明间距为 .25rem，控件与错误为 .5rem。宽页面里的单项仍可能很窄。

```tsx verify
import { useId } from "react"
import { Field, FieldContent, FieldDescription, FieldError, FieldLabel, Input } from "@exre/exui"

export function SettingsField() {
  const id = useId()
  return <Field data-invalid>
    <FieldLabel htmlFor={id}>邮箱</FieldLabel>
    <FieldDescription id={`${id}-description`}>接收项目更新</FieldDescription>
    <FieldContent>
      <Input id={id} defaultValue="invalid" aria-invalid aria-describedby={`${id}-description ${id}-error`} />
      <FieldError id={`${id}-error`}>请输入有效邮箱。</FieldError>
    </FieldContent>
  </Field>
}
```

**ExUI 适配**

### FieldLabel 内的 Checkbox

`FieldLabel` 包含 `Checkbox` 时，选中状态通过复选框自身的底色和勾号呈现，标签背景保持不变。复选卡片和设置行都遵循这一规则，点击标签仍可切换复选框。

请阅读[FieldLabel 内的 Checkbox](./checkbox.mdx)，了解完整用法。

**ExUI 适配**

### FieldLabel 内的 Switch

`FieldLabel` 包含 `Switch` 时，切换开关只改变轨道状态，不会给整行标签填充选中色。卡片和设置行都遵循这一规则。可用标签组合构建整行可点的开关设置，无需另加整行选中背景。

- [在线示例](../../../../examples/c-field-1/)

**ExUI 适配**

### Radio 字段选中态

`FieldLabel` 包裹 `RadioGroupItem` 时，选中选项不会自动改变标签背景，卡片与设置行组合也遵循此规则。选中状态由单选圆点与指示器表达，点击标签和方向键选择仍可使用。需要带底色的选中行或卡片时，请显式设置背景类名。

## 基本用法

将标签、控件、说明与错误信息放在同一字段组中。

### 当前示例源码摘录

```tsx source="c-field-1"
import { Field, FieldDescription, FieldLabel, Input } from "@exre/exui"

<Field>
          <FieldLabel htmlFor={exampleId("profile-name")}>
            {<ExampleText>Full Name </ExampleText>}<span className="text-destructive">*</span>
          </FieldLabel>
          <Input
            id={exampleId("profile-name")}
            placeholder={copyExample("Enter your full name")}
            required
          />
          <FieldDescription>
            {<ExampleText>This name will be displayed on your public profile. </ExampleText>}</FieldDescription>
        </Field>
```

## 独立字段

显式组合 `Field`、`FieldLabel`、`FieldContent`、`FieldDescription` 和 `FieldError`。每个可聚焦控件都需要 ID，以 `htmlFor` 关联标签；说明和错误的 ID 放入 `aria-describedby`，出错时设置 `aria-invalid`。使用 `orientation="responsive"` 时，用 `FieldGroup` 提供查询容器。纯展示内容用 `FieldLabel asChild` 和 span 标签。

宽度与对齐示例使用自身容器的 `21.75rem` 阈值：`9rem` 标签、最小 `12rem` 控件与 `.75rem` 间距。控件上限和对齐仅在阈值以上生效，窄时恢复全宽。复用此配方时需复制完整源码及其局部样式表。

控件需要绑定校验草稿时，使用 [Form](../exui/form.mdx) 和 `FormField`。

```tsx verify
import { useId, useState } from "react"
import { Field, FieldContent, FieldDescription, FieldError, FieldGroup, FieldLabel, Input } from "@exre/exui"
export function StandaloneEmail() {
  const id = useId()
  const [email, setEmail] = useState("")
  const invalid = email.length > 0 && !email.includes("@")
  return <FieldGroup><Field orientation="responsive" data-invalid={invalid}>
    <FieldLabel htmlFor={id}>Email</FieldLabel>
    <FieldContent>
      <Input id={id} type="email" value={email} onChange={event => setEmail(event.target.value)} aria-invalid={invalid} aria-describedby={`${id}-description${invalid ? ` ${id}-error` : ""}`} />
      <FieldDescription id={`${id}-description`}>Account notifications.</FieldDescription>
      {invalid && <FieldError id={`${id}-error`}>Enter a valid email.</FieldError>}
    </FieldContent>
  </Field></FieldGroup>
}
```
