Toggle Group：协调一组选项的按下状态。

{/* exui-capabilities:begin:docs */}
## ExUI 能力

**ExUI 新增**

### 共用 Glass 材质

`glass` 属性与精确的 `ex-glass` 类名都可启用 ExUI 材质；每个表面分别选择，包括 Select 弹层。先导入 `@exre/exui/style.css`。如需可选折射，每个 document 挂载一个 `GlassSeed`。它渲染不可见的 SVG 滤镜定义，不占可见布局内容，并非 Provider，可在服务端渲染；没有它也有基础材质。浏览器支持检测只确认滤镜声明可被接受，不能证明折射被正确绘制；关键视觉效果需在目标浏览器检查。

本家族支持 Glass 的公开组件: `ToggleGroupItem`。

请将此表面保留在常规的组件组合中；这个封装只为该表面启用 Glass。

```tsx verify
import type { ComponentProps } from "react"
import { ToggleGroupItem } from "@exre/exui"

export function GlassExample(props: ComponentProps<typeof ToggleGroupItem>) {
  return <ToggleGroupItem {...props} glass />
}
```

请阅读[共用 Glass 材质](../exui/glass.mdx)，了解完整用法。

**ExUI 适配**

### Toggle 选中态

`Toggle` 和 `ToggleGroupItem` 在鼠标移开后仍保留可见的选中底色，应用工具类位于公共样式之上时也一样。默认与描边样式均支持鼠标和键盘切换。使用 `glass` 时，控件遵循共享的 Glass 状态材质；禁用控件保持默认 Glass 材质。

请阅读[Toggle 选中态](./toggle.mdx)，了解完整用法。

## 基本用法

为每个选项赋值，将整组用于相关的视图或格式选择。

### 当前示例源码摘录

```tsx source="c-toggle-group-1"
import { ToggleGroup, ToggleGroupItem } from "@exre/exui"

<ToggleGroup type="multiple" spacing={1}>
        <ToggleGroupItem value="bold" aria-label={copyExample("Toggle bold")}>
          <BoldIcon  />
        </ToggleGroupItem>
        <ToggleGroupItem value="italic" aria-label={copyExample("Toggle italic")}>
          <ItalicIcon  />
        </ToggleGroupItem>
        <ToggleGroupItem value="underline" aria-label={copyExample("Toggle underline")}>
          <UnderlineIcon  />
        </ToggleGroupItem>
      </ToggleGroup>
```
