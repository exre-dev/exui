## ExUI 能力

**ExUI 新增**

### 共用 Glass 材质

`glass` 属性与精确的 `ex-glass` 类名都可启用 ExUI 材质；每个表面分别选择，包括 Select 弹层。先导入 `@exre/exui/style.css`。如需可选折射，每个 document 挂载一个 `GlassSeed`。它渲染不可见的 SVG 滤镜定义，不占可见布局内容，并非 Provider，可在服务端渲染；没有它也有基础材质。浏览器支持检测只确认滤镜声明可被接受，不能证明折射被正确绘制；关键视觉效果需在目标浏览器检查。

本家族支持 Glass 的公开组件: `Attachment`。

请将此表面保留在常规的组件组合中；这个封装只为该表面启用 Glass。

```tsx verify
import type { ComponentProps } from "react"
import { Attachment } from "@exre/exui"

export function GlassExample(props: ComponentProps<typeof Attachment>) {
  return <Attachment {...props} glass />
}
```

请阅读[共用 Glass 材质](../exui/glass.mdx)，了解完整用法。

**ExUI 适配**

### Attachment 媒体圆角

`AttachmentMedia` 的内嵌圆角与外层 `Attachment` 保持同心。图片预览、图标和文件媒体都使用这套内外几何关系。将媒体保留在 `Attachment` 内，密度或外层圆角变化时才能继续对齐。

## 基本用法

先展示文件名与类型，再添加预览、下载或移除操作。

### 当前示例源码摘录

```tsx source="c-attachment-1"
import { Attachment, AttachmentContent, AttachmentDescription, AttachmentMedia, AttachmentTitle } from "@exre/exui"

<Attachment>
  <AttachmentMedia />
  <AttachmentContent>
    <AttachmentTitle />
    <AttachmentDescription />
  </AttachmentContent>
</Attachment>
```
