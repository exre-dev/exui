Pagination：按页浏览有序结果集。

## 基本用法

将当前页码与总页数连接到实际结果查询。

### 当前示例源码摘录

```tsx source="c-pagination-1"
import { Pagination, PaginationContent, PaginationItem } from "@exre/exui"

<Pagination>
  <PaginationContent>
    <PaginationItem />
    <PaginationItem />
  </PaginationContent>
</Pagination>
```
