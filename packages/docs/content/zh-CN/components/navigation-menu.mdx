Navigation Menu：连接顶层目标与下级导航链接。

{/* exui-capabilities:begin:docs */}
## ExUI 能力

**ExUI 适配**

### NavigationMenu 弹层宽度

默认 `NavigationMenuViewport` 在桌面宽度下跟随实测内容宽度，在 `md` 断点以下铺满宽度。即使应用的 Tailwind 工具类在 ExUI CSS 后加载，菜单选项仍应可见、可点击。普通菜单无需手动覆盖默认弹层宽度。

同时保留 `NavigationMenuContent` 的默认响应式宽度。给内容区或弹层添加不受断点限制的 `w-full`，可能限制桌面布局的宽度测量并裁掉菜单链接。

## 基本用法

按导航类别组织目标链接，让触发文字能说明目的地。

### 当前示例源码摘录

```tsx source="c-navigation-menu-1"
import { NavigationMenu, NavigationMenuItem, NavigationMenuList } from "@exre/exui"

<NavigationMenu>
  <NavigationMenuList>
    <NavigationMenuItem />
    <NavigationMenuItem />
  </NavigationMenuList>
</NavigationMenu>
```
