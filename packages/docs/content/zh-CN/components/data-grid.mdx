Data Grid：结合表格展示、编辑与选择。

{/* exui-capabilities:begin:docs */}
## ExUI 能力

**ExUI 适配**

### 紧凑组件内边距

ExUI 将默认 Card 内边距、`AlertDialogContent` 四边、`SheetHeader` 与 `SheetFooter` 四边、`CommandEmpty` 及 DataGrid 空表和筛选空提示的上下、Gantt 无资源提示四边、纵向 `TimelineItem` 非末项的底部 padding 统一为 `1rem`（16px 根字号下为 16px）。空状态仅在对应提示渲染时生效；时间轴末项不额外增加底部 padding。调用方仍可用类名覆盖默认值。

请阅读[紧凑组件内边距](./card.mdx)，了解完整用法。

- [在线示例](../../../../examples/c-data-grid-22/)

**ExUI 新增**

### 共用 Glass 材质

`glass` 属性与精确的 `ex-glass` 类名都可启用 ExUI 材质；每个表面分别选择，包括 Select 弹层。先导入 `@exre/exui/style.css`。如需可选折射，每个 document 挂载一个 `GlassSeed`。它渲染不可见的 SVG 滤镜定义，不占可见布局内容，并非 Provider，可在服务端渲染；没有它也有基础材质。浏览器支持检测只确认滤镜声明可被接受，不能证明折射被正确绘制；关键视觉效果需在目标浏览器检查。

本家族支持 Glass 的公开组件: `DataGridContainer`。

请将此表面保留在常规的组件组合中；这个封装只为该表面启用 Glass。

```tsx verify
import type { ComponentProps } from "react"
import { DataGridContainer } from "@exre/exui"

export function GlassExample(props: ComponentProps<typeof DataGridContainer>) {
  return <DataGridContainer {...props} glass />
}
```

请阅读[共用 Glass 材质](../exui/glass.mdx)，了解完整用法。

**ExUI 新增**

### 密度与根字号缩放

紧凑密度作用域会改变 `Button`、`Input`、`Textarea`、`Select`、`NativeSelect` 和 `InputGroup` 的默认几何尺寸。显式尺寸和复杂组件布局并非都会随该作用域缩小。CSS 中的 `rem` 尺寸随根字号变化。部分第三方组件只接受数字尺寸；ExUI 在 DOM 边界换算自己的默认值，并在根字号变化后更新。调用者显式传入的数字仍是像素，不应再次换算。

请阅读[密度与根字号缩放](../tokens/density.mdx)，了解完整用法。

- [在线示例](../../../../examples/c-data-grid-1/)

**ExUI 新增**

### 内置图表与表格运行时

组合 ExUI 图表或 DataGrid 时，从根入口导入 `Recharts` 和 `TanStackTable`。这两个命名空间与 ExUI 组件使用同一份打包实例。封装后的 Recharts 坐标轴、提示和图例，会按 document 根字号缩放未传入的数字默认值；`TanStackTable.useTable` 及其应用 hook 也会缩放未传入的列尺寸。显式数字仍按像素解释；非 React 的 `constructTable` 保留上游像素默认值。

请阅读[内置图表与表格运行时](./chart.mdx)，了解完整用法。

- [在线示例](../../../../examples/c-data-grid-1/)

## 基本用法

先定义稳定行 id 与列配置，再启用选择或编辑。

### 当前示例源码摘录

```tsx source="c-data-grid-1"
import { DataGrid, DataGridContainer, DataGridPagination, DataGridScrollArea, DataGridTable } from "@exre/exui"

<DataGrid table={table} recordCount={demoData.length} i18n={exampleLocales[language].dataGrid}>
      <div className="w-full space-y-2.5">
        <DataGridContainer>
          <DataGridScrollArea>
            <DataGridTable />
          </DataGridScrollArea>
        </DataGridContainer>
        <DataGridPagination />
      </div>
    </DataGrid>
```
