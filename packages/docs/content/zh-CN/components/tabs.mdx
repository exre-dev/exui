Tabs：在相关内容面板之间切换。

{/* exui-capabilities:begin:docs */}
## ExUI 能力

**ExUI 适配**

### ExUI 标签页外观

`TabsList` 支持 `variant="default"`、`"primary"` 和 `"line"`。有底色的变体使用胶囊形横向轨道与触发项。竖向触发项保持胶囊形，外框圆角按单项高度和外围内边距协调，让首尾两项落在外框弧线以内。

只有选中的触发项带轻微投影，并随主题调整。`primary` 变体同时采用主色背景与前景色。`line` 变体保留透明背景和选中指示线，不加选中投影。选中项的键盘焦点仍清晰可见。

**ExUI 新增**

### 共用 Glass 材质

`glass` 属性与精确的 `ex-glass` 类名都可启用 ExUI 材质；每个表面分别选择，包括 Select 弹层。先导入 `@exre/exui/style.css`。如需可选折射，每个 document 挂载一个 `GlassSeed`。它渲染不可见的 SVG 滤镜定义，不占可见布局内容，并非 Provider，可在服务端渲染；没有它也有基础材质。浏览器支持检测只确认滤镜声明可被接受，不能证明折射被正确绘制；关键视觉效果需在目标浏览器检查。

本家族支持 Glass 的公开组件: `TabsList`, `TabsTrigger`。

请将此表面保留在常规的组件组合中；这个封装只为该表面启用 Glass。

```tsx verify
import type { ComponentProps } from "react"
import { TabsList } from "@exre/exui"

export function GlassExample(props: ComponentProps<typeof TabsList>) {
  return <TabsList {...props} glass />
}
```

请阅读[共用 Glass 材质](../exui/glass.mdx)，了解完整用法。

## 基本用法

给每个触发项稳定的值，并配对相应内容面板。

### 当前示例源码摘录

```tsx source="c-tabs-1"
import { Card, Tabs, TabsContent, TabsList, TabsTrigger } from "@exre/exui"

<Tabs defaultValue="account">
  <TabsList>
    <TabsTrigger value="account" />
    <TabsTrigger value="password" />
  </TabsList>
  <TabsContent value="account">
    <Card />
  </TabsContent>
</Tabs>
```
