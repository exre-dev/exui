Alert Dialog：在重要操作前请求明确确认。

{/* exui-capabilities:begin:docs */}
## ExUI 能力

**ExUI 适配**

### 紧凑组件内边距

ExUI 将默认 Card 内边距、`CommandEmpty` 及 DataGrid 空表和筛选空提示的上下、Gantt 无资源提示四边、纵向 `TimelineItem` 非末项的底部 padding 统一为 `1rem`（16px 根字号下为 16px）。`DialogContent`、`AlertDialogContent`、`SheetHeader` 与 `SheetFooter` 的默认四边 padding 均为 `1.5rem`（16px 根字号下为 24px），与 ReUI 一致。空状态仅在对应提示渲染时生效；时间轴末项不额外增加底部 padding。调用方仍可用类名覆盖默认值。

请阅读[紧凑组件内边距](./card.mdx)，了解完整用法。

- [在线示例](../../../../examples/c-alert-dialog-1/)

**ExUI 新增**

### 共用 Glass 材质

`glass` 属性与精确的 `ex-glass` 类名都可启用 ExUI 材质；每个表面分别选择，包括 Select 弹层。先导入 `@exre/exui/style.css`。如需可选折射，每个 document 挂载一个 `GlassSeed`。它渲染不可见的 SVG 滤镜定义，不占可见布局内容，并非 Provider，可在服务端渲染；没有它也有基础材质。浏览器支持检测只确认滤镜声明可被接受，不能证明折射被正确绘制；关键视觉效果需在目标浏览器检查。

本家族支持 Glass 的公开组件: `AlertDialogContent`。

请将此表面保留在常规的组件组合中；这个封装只为该表面启用 Glass。

```tsx verify
import type { ComponentProps } from "react"
import { AlertDialogContent } from "@exre/exui"

export function GlassExample(props: ComponentProps<typeof AlertDialogContent>) {
  return <AlertDialogContent {...props} glass />
}
```

请阅读[共用 Glass 材质](../exui/glass.mdx)，了解完整用法。

## 基本用法

先写明标题与后果，再提供确认和取消操作。

### 当前示例源码摘录

```tsx source="c-alert-dialog-1"
import { AlertDialog, AlertDialogContent, AlertDialogFooter, AlertDialogHeader, AlertDialogTrigger, Button } from "@exre/exui"

<AlertDialog>
  <AlertDialogTrigger asChild>
    <Button variant="outline" />
  </AlertDialogTrigger>
  <AlertDialogContent>
    <AlertDialogHeader />
    <AlertDialogFooter />
  </AlertDialogContent>
</AlertDialog>
```
