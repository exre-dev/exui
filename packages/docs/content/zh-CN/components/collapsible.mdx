Collapsible：在当前区域展开可选详情。

## 基本用法

在同一个展开根节点中放置触发器与可选内容。

### 当前示例源码摘录

```tsx source="c-collapsible-1"
import { Collapsible, CollapsibleContent } from "@exre/exui"

<Collapsible>
  <CollapsibleContent />
</Collapsible>
```
