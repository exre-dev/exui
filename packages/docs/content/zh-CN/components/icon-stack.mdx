Icon Stack：将多个图标块紧凑组合。

## 基本用法

用重叠图标块表示少量相关对象，在图标组之外保留文字标签。

### 当前示例源码摘录

```tsx source="c-icon-stack-1"
import { IconStack } from "@exre/exui"

<IconStack aria-hidden="true">
        <LayersIcon className="size-4" />
      </IconStack>
```
