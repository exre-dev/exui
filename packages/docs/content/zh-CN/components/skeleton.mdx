Skeleton：内容加载时预留布局形状。

## 基本用法

让加载占位形状接近最终内容，减少布局跳动。

### 当前示例源码摘录

```tsx source="c-skeleton-1"
import { Skeleton } from "@exre/exui"

<Skeleton className="h-12 w-12 rounded-full" />
```
