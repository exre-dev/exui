Icon Stack: Combines multiple icon tiles in a compact group.

## Basic usage

Use overlapping tiles for a small related set and retain labels outside the icon cluster.

### Current example source excerpt

```tsx source="c-icon-stack-1"
import { IconStack } from "@exre/exui"

<IconStack aria-hidden="true">
        <LayersIcon className="size-4" />
      </IconStack>
```
