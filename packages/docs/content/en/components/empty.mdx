Empty: Explains an empty collection and its next action.

## Basic usage

State why no items appear and offer the next useful action where one exists.

### Current example source excerpt

```tsx source="c-empty-1"
import { Button, Empty, EmptyContent, EmptyDescription, EmptyHeader, EmptyTitle } from "@exre/exui"

<Empty>
  <EmptyHeader>
    <EmptyTitle />
    <EmptyDescription />
  </EmptyHeader>
  <EmptyContent>
    <Button variant="link" asChild />
  </EmptyContent>
</Empty>
```
