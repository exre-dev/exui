Frame: Adds a structured boundary around content.

## Basic usage

Wrap one media or content region when it needs a distinct inset boundary.

### Current example source excerpt

```tsx source="c-frame-1"
import { Frame, FrameDescription, FrameHeader, FramePanel, FrameTitle } from "@exre/exui"

<Frame>
  <FrameHeader>
    <FrameTitle />
    <FrameDescription />
  </FrameHeader>
  <FramePanel />
</Frame>
```
