Icon Tile: Places an icon in a bounded visual tile.

## Basic usage

Use a tile to keep one decorative or status icon aligned within a fixed surface.

### Current example source excerpt

```tsx source="c-icon-tile-1"
import { IconTile } from "@exre/exui"

<IconTile aria-hidden="true">
        <FolderIcon  />
      </IconTile>
```
