## ExUI capabilities

**ExUI addition**

### Shared Glass material

`glass` and the exact `ex-glass` class opt a surface into ExUI's material; each surface opts in independently, including a Select popup. Import `@exre/exui/style.css`.

Glass surfaces in this family: `Alert`.

Keep this surface in its usual family composition; the wrapper opts that surface into Glass.

```tsx verify
import type { ComponentProps } from "react"
import { Alert } from "@exre/exui"

export function GlassExample(props: ComponentProps<typeof Alert>) {
  return <Alert {...props} glass />
}
```

Read [Shared Glass material](../exui/glass.mdx) for complete usage guidance.
{/* exui-capabilities:end:docs */}

## Basic usage

Compose a title and description for information that should remain visible until addressed.

### Current example source excerpt

```tsx source="c-alert-1"
import { Alert, AlertDescription, AlertTitle } from "@exre/exui"

<Alert>
      <AlertTitle>{<ExampleText>Alert!</ExampleText>}</AlertTitle>
      <AlertDescription>
        {<ExampleText>This is an alert with a title and description. </ExampleText>}</AlertDescription>
    </Alert>
```
