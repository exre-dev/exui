Collapsible: Reveals optional details within a section.

## Basic usage

Wrap a trigger and the optional content in the same disclosure root.

### Current example source excerpt

```tsx source="c-collapsible-1"
import { Collapsible, CollapsibleContent } from "@exre/exui"

<Collapsible>
  <CollapsibleContent />
</Collapsible>
```
