## ExUI capabilities

**ExUI adaptation**

### Switch inside FieldLabel

When a `FieldLabel` contains a `Switch`, toggling the switch changes its track without filling the entire label background. This applies to card and settings-row labels.

Read [Switch inside FieldLabel](./field.mdx) for complete usage guidance.

- [Live example](../../../../examples/c-switch-1/)

## Basic usage

Use a switch for a setting that takes effect immediately, paired with a descriptive label.
