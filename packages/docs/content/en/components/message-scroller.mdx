## Basic usage

Place the message list inside the scroller and let new messages follow its scroll policy.

### Current example source excerpt

```tsx source="c-message-scroller-1"
import { Message, MessageScroller, MessageScrollerButton, MessageScrollerContent, MessageScrollerViewport } from "@exre/exui"

<MessageScroller>
  <MessageScrollerViewport aria-label={copyExample("Webhook incident transcript")}>
    <MessageScrollerContent />
  </MessageScrollerViewport>
  <MessageScrollerButton variant="outline" />
</MessageScroller>
```
