## Basic usage

Each filter appears as one joined control with internal dividers. Labels stay on one line; long field paths and operators shorten within narrow containers while their full text remains in the control's accessible name and editor. Keep the toolbar free to wrap whole filters rather than wrapping individual words.

Describe each filter field and operator, then apply the structured result to the data query.

### Current example source excerpt

```tsx source="c-filters-1"
import { Filters } from "@exre/exui"

<Filters operatorLabels={exampleLocales.filterOperators} labels={exampleLocales.filters}
        fields={copyExampleData(fields)}
        query={query}
        onQueryChange={setQuery}

      />
```
