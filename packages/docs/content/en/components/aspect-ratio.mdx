Aspect Ratio: Keeps media at a declared width-to-height ratio.

## Basic usage

Wrap media in the ratio container before assigning its image or video content.

### Current example source excerpt

```tsx source="c-aspect-ratio-1"
import { AspectRatio } from "@exre/exui"

<AspectRatio
        ratio={16 / 9}
        className="bg-muted rounded-xl overflow-hidden border"
      >
        <img
          src="/examples/reui/photos/b7c3c9f06c82916658.jpg"
          alt={copyExample("16:9")}
          width={1000}
          height={800}
          className="h-full w-full object-cover"
        />
      </AspectRatio>
```
