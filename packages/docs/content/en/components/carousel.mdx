Carousel: Browses a sequence of visual items.

## Basic usage

Group slides under one carousel and give navigation controls clear labels.

### Current example source excerpt

```tsx source="c-carousel-1"
import { Carousel, CarouselContent, CarouselPrevious } from "@exre/exui"

<Carousel>
  <CarouselContent />
  <CarouselPrevious />
</Carousel>
```
