## ExUI capabilities

**ExUI addition**

### Shared Glass material

`glass` and the exact `ex-glass` class opt a surface into ExUI's material; each surface opts in independently, including a Select popup. Import `@exre/exui/style.css`.

Glass surfaces in this family: `ToggleGroupItem`.

Keep this surface in its usual family composition; the wrapper opts that surface into Glass.

```tsx verify
import type { ComponentProps } from "react"
import { ToggleGroupItem } from "@exre/exui"

export function GlassExample(props: ComponentProps<typeof ToggleGroupItem>) {
  return <ToggleGroupItem {...props} glass />
}
```

Read [Shared Glass material](../exui/glass.mdx) for complete usage guidance.

**ExUI adaptation**

### Toggle selection appearance

`Toggle` and `ToggleGroupItem` keep a visible selected background after the pointer leaves, including when application utilities load above the public stylesheet. Default and outline variants support mouse and keyboard toggling.

Read [Toggle selection appearance](./toggle.mdx) for complete usage guidance.

## Basic usage

Give each item a value and use the group for one related set of view or formatting choices.

### Current example source excerpt

```tsx source="c-toggle-group-1"
import { ToggleGroup, ToggleGroupItem } from "@exre/exui"

<ToggleGroup type="multiple" spacing={1}>
        <ToggleGroupItem value="bold" aria-label={copyExample("Toggle bold")}>
          <BoldIcon  />
        </ToggleGroupItem>
        <ToggleGroupItem value="italic" aria-label={copyExample("Toggle italic")}>
          <ItalicIcon  />
        </ToggleGroupItem>
        <ToggleGroupItem value="underline" aria-label={copyExample("Toggle underline")}>
          <UnderlineIcon  />
        </ToggleGroupItem>
      </ToggleGroup>
```
