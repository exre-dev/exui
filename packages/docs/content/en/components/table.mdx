Table: Displays rows and columns with consistent styling.

## Basic usage

Use a header row to label columns and body rows for the records beneath them.

### Current example source excerpt

```tsx source="c-table-1"
import { Table, TableCaption, TableHead, TableHeader, TableRow } from "@exre/exui"

<Table>
  <TableCaption />
  <TableHeader>
    <TableRow />
  </TableHeader>
</Table>
```
