Context Menu: Shows actions for the current item or pointer context.

{/* exui-capabilities:begin:docs */}
## ExUI capabilities

**ExUI addition**

### Shared Glass material

`glass` and the exact `ex-glass` class opt a surface into ExUI's material; each surface opts in independently, including a Select popup. Import `@exre/exui/style.css`.

Glass surfaces in this family: `ContextMenuContent`, `ContextMenuSubContent`.

Keep this surface in its usual family composition; the wrapper opts that surface into Glass.

```tsx verify
import type { ComponentProps } from "react"
import { ContextMenuContent } from "@exre/exui"

export function GlassExample(props: ComponentProps<typeof ContextMenuContent>) {
  return <ContextMenuContent {...props} glass />
}
```

Read [Shared Glass material](../exui/glass.mdx) for complete usage guidance.
{/* exui-capabilities:end:docs */}

## Basic usage

Attach the menu to the object being acted on, and keep destructive actions distinguishable.

### Current example source excerpt

```tsx source="c-context-menu-1"
import { ContextMenu, ContextMenuContent, ContextMenuGroup, ContextMenuTrigger } from "@exre/exui"

<ContextMenu>
  <ContextMenuTrigger />
  <ContextMenuContent>
    <ContextMenuGroup />
  </ContextMenuContent>
</ContextMenu>
```
