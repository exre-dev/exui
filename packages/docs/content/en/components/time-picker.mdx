Time Picker: Chooses a time with dedicated time controls.

## Basic usage

Choose the time granularity needed by the task and keep the displayed time tied to one value.

### Current example source excerpt

```tsx source="c-time-picker-1"
import { TimePicker, TimePickerPanel } from "@exre/exui"

<TimePicker i18n={exampleLocales.timePicker}
          value={value}
          onValueChange={setValue}
          aria-label={copyExample("Meeting time")}
        >
          <TimePickerPanel />
        </TimePicker>
```
