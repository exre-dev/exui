Calendar: Selects dates in a visual month view.

{/* exui-capabilities:begin:docs */}
## ExUI capabilities

**ExUI adaptation**

### Calendar selection shape

Single and multiple selected dates stay circular at the first and last weekday columns, including layouts with week numbers. A date range keeps round endpoints and a connected middle band. ExUI provides these edge shapes by default; use the ordinary `Calendar` selection props without per-column radius overrides.

- [Live example](../../../../examples/c-calendar-1/)
{/* exui-capabilities:end:docs */}

## Basic usage

Choose the intended selection mode and handle the selected date in application state.

### Current example source excerpt

```tsx source="c-calendar-1"
import { Calendar } from "@exre/exui"

<Calendar labels={exampleLocales.calendarLabels} locale={exampleLocale} defaultMonth={new Date(EXAMPLE_EPOCH)} mode="single" onSelect={setDate} selected={date} />
```
