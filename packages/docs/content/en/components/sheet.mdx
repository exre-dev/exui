## ExUI capabilities

**ExUI adaptation**

### Compact component padding

ExUI uses `1rem` padding (16px at a 16px root) for default Card insets, all sides of `AlertDialogContent`, `SheetHeader` and `SheetFooter`, vertical padding in `CommandEmpty` and DataGrid empty-table/filter messages, all sides of Gantt's no-resource message, and bottom padding between vertical `TimelineItem` entries. Empty-state padding appears only when that state is rendered; Timeline's last item has no added bottom padding.

Read [Compact component padding](./card.mdx) for complete usage guidance.

- [Live example](../../../../examples/c-sheet-1/)

**ExUI addition**

### Shared Glass material

`glass` and the exact `ex-glass` class opt a surface into ExUI's material; each surface opts in independently, including a Select popup. Import `@exre/exui/style.css`.

Glass surfaces in this family: `SheetContent`.

Keep this surface in its usual family composition; the wrapper opts that surface into Glass.

```tsx verify
import type { ComponentProps } from "react"
import { SheetContent } from "@exre/exui"

export function GlassExample(props: ComponentProps<typeof SheetContent>) {
  return <SheetContent {...props} glass />
}
```

Read [Shared Glass material](../exui/glass.mdx) for complete usage guidance.
{/* exui-capabilities:end:docs */}

## Basic usage

Use the edge panel for related work while keeping the originating context visible.

### Current example source excerpt

```tsx source="c-sheet-1"
import { Button, Sheet, SheetContent, SheetFooter, SheetHeader, SheetTrigger } from "@exre/exui"

<Sheet>
  <SheetTrigger asChild>
    <Button variant="outline" />
  </SheetTrigger>
  <SheetContent>
    <SheetHeader />
    <SheetFooter />
  </SheetContent>
</Sheet>
```
